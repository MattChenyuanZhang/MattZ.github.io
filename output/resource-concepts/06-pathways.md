# 06 — Learning pathways

Independent source review of resources.html and stylesheet.css.

Findings: The page has 19 useful resources but no visible page title or introduction. Eight topic headings sit directly inside a single ul, which gives the document a weak semantic outline. General and CS graduate school advice overlap; readers must scan the entire list to decide where to begin. Resource labels inconsistently combine author and title, and PDF links lack a visible format label. EB Garamond is declared but only Inter is loaded on this page, so the intended typography is not guaranteed. The desktop navigation relies on a 300px margin and the mobile navigation requires horizontal scrolling.

Proposal: Four pathways — Study well, Prepare for a PhD, Do meaningful work, Build a career — convert topic sorting into visitor intentions. Use a horizontal chapter index, large chapter numerals, short introductions, and simple resource rows. Merge graduate advice into one chapter; group cold email and recruiting resources together; retain AI reflections within meaningful work. Keep every original destination. Give PDFs explicit labels, use a real h1 and sequential h2 sections, and make chapter navigation wrap on small screens. No invented progress tracking or ratings. New introductory copy is proposed editorial copy, not existing content.

Validation: Static source inspection only; no runtime browser or external link testing performed by this reviewer. The image illustrates the proposed hierarchy rather than implemented code.
