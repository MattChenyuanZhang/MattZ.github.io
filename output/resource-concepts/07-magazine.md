# 07 — Editorial reading room

Independent source-based evaluation of resources.html and stylesheet.css. No live click testing performed.

## Findings

- Useful topical groups and direct links, but no visible page title or framing.
- Category headings are direct children of a ul; there is no h1, weakening semantic heading navigation.
- Long titles and separate author links form an undifferentiated wall of blue text.
- Desktop navigation relies on a 300px margin; mobile navigation horizontally scrolls.
- PDF, archive, and social destinations are not identified.
- EB Garamond is requested in CSS while the page loads Inter.

## Proposal

An ivory-and-burgundy literary magazine composition with a clear title, featured existing Paul Graham essay, categorized ruled rows, and a category index. Preserve every original resource in implementation, identify formats, add semantic sections and visible keyboard focus. Stack the feature and wrap category links on mobile. Featured placement is a design proposal, not a claim about Matt's favorites.

Generated with built-in image generation. Illustrative design, not implemented UI.
