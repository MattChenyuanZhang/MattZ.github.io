# Trunk atlas

Generated using the built-in image generation tool. Saved as trunks-atlas-v1.png with an alpha channel; not yet integrated into the site.

Use case: stylized-concept. Asset type: transparent watercolor botanical trunk atlas for a quiet dreamlike procedural website garden. Create SIX separate isolated bare deciduous tree trunks in a spacious 3-column by 2-row arrangement, generous transparent gaps, each complete root base and all branch tips visible. Each trunk must have a distinctly different natural silhouette: graceful S curve with a sweeping right fork, gentle left lean with asymmetrical forks, short gnarled curved trunk with open spreading branches, slender upright trunk with subtle irregular bends, broad low fork with twisting arms, elegant wind-swept curved trunk. NOT straight geometric sticks. Organic continuous taper from broad root base to very fine twig tips, uneven asymmetric bifurcations, gently twisting wood, subtle knots, delicate watercolor bark grain and overlapping translucent warm grey olive and pale beige pigment. Refined hand-painted botanical watercolor matching pale sage/celadon watercolor leaves; ethereal light and soft but clearly visible enough to reduce opacity in software. Trunks and branch skeletons only, NO leaves, NO soil, NO ground, NO pots, NO full landscape. Small discreet root flares, no expansive roots. Each trunk occupies its own cell without touching or overlapping another. Genuinely transparent background with preserved alpha, no paper rectangle, no white or colored background, no baked checkerboard, no shadows. No text, no labels, no borders. Avoid vector shapes, mechanically repeated forks, uniform cylindrical branches, dark outlines, photographic bark, and heavy contrast.
